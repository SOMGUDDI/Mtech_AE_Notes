CAN Bit Stuffing Mechanism, Bit Timing & Synchronization

Estimated Read Time: 12–15 mins

[SEC 01] Quick Overview

To maintain clock synchronization between unsynchronized node crystal oscillators without dedicating a separate clock wire, CAN employs two critical lower-layer mechanisms: Bit Stuffing (which guarantees frequent signal edges) and Nominal Bit Timing Segmentation (which divides every bit into time quanta to account for propagation delays and phase drift).

[SEC 02] Learning Objectives & Prerequisites

What You Will Master:
  • Explain the rule of Bit Stuffing (5 consecutive identical polarity bits).
  • Identify which frame fields are bit-stuffed and which are fixed-form (unstuffed).
  • Analyze Nominal Bit Time segments: Sync_Seg, Prop_Seg, Phase_Seg1, and Phase_Seg2.
  • Calculate CAN baud rates, Time Quanta ($T_q$), sample point percentages, and Synchronization Jump Width (SJW).
Prerequisites: CAN Protocol Architecture & Differential Physical Layer, CAN Frame Format.

[SEC 03] Core Concept & Physical Intuition

CAN does not have a clock line. Receivers stay synchronized by detecting falling voltage edges (recessive-to-dominant transitions). If a data payload contains all zeros (e.g., 64 dominant bits), a receiver clock that is slightly fast or slow will drift and miscount the bits. To prevent this, the transmitter automatically injects an opposite-polarity 'stuff bit' after every 5 consecutive identical bits. The receiver recognizes and removes this extra bit before passing data to the microcontroller.

[SEC 05] Rigorous Engineering Theory & Derivations

// RIGOROUS ENGINEERING THEORY

Let's analyze Nominal Bit Time ($t_{bit}$) segmentation in detail: A single CAN bit time is divided into non-overlapping Time Quanta ($T_q$), derived from the microcontroller peripheral clock ($f_{osc}$) via a Baud Rate Prescaler (BRP): $$T_q = \frac{BRP}{f_{osc}}$$ The bit is partitioned into four functional segments: 1. **SYNC_SEG (1 $T_q$):** Used to synchronize the various nodes on the bus. An edge is expected to lie within this segment. 2. **PROP_SEG (1 to 8 $T_q$):** Compensates for physical propagation delays across cables, transceivers, and input comparators. 3. **PHASE_SEG1 (1 to 8 $T_q$):** Compensates for phase edge errors. May be lengthened by resynchronization. 4. **PHASE_SEG2 (2 to 8 $T_q$):** Compensates for phase edge errors. May be shortened by resynchronization. **Sample Point:** The precise instant in time where the CAN controller reads the bus state: $\text{Sample Point} = \frac{\text{SYNC\_SEG} + \text{PROP\_SEG} + \text{PHASE\_SEG1}}{\text{Total } T_q} \times 100\%$. **Synchronization Jump Width (SJW):** The maximum number of Time Quanta by which Phase_Seg1 can be lengthened or Phase_Seg2 shortened during resynchronization (typically 1 to 4 $T_q$).

[SEC 08] Step-by-Step Operational Principle

Hard Synchronization vs Resynchronization: 1. **Hard Synchronization:** Occurs on the falling edge of the Start-of-Frame (SOF) bit. The receiver's internal bit counter is instantly reset to zero within SYNC_SEG. 2. **Resynchronization:** Occurs on subsequent recessive-to-dominant edges during frame transmission. If an edge occurs before SYNC_SEG (early edge), Phase_Seg2 is shortened by up to SJW. If an edge occurs after SYNC_SEG (late edge), Phase_Seg1 is lengthened by up to SJW. This dynamically eliminates clock drift.

Nominal Bit Rate and Time Quanta Equations
T_q = \frac{BRP}{f_{clk}}, \quad T_{bit} = T_q \cdot (SYNC\_SEG + PROP\_SEG + PHASE\_SEG1 + PHASE\_SEG2), \quad \text{Baud} = \frac{1}{T_{bit}}

Worked Numerical Example:
For f_clk = 40 MHz, BRP = 5 -> T_q = 5 / 40 MHz = 125 ns. If total T_q count = 16, then T_bit = 16 × 125 ns = 2000 ns = 2 μs. Baud rate = 1 / 2 μs = 500,000 bps = 500 kbps.

// S32K144 / ARM Cortex-M4 FlexCAN Bit Timing Register Configuration (500 kbps)
void configure_flexcan_bit_timing(void) {
    // Enable CAN clock gate in PCC
    PCC->PCCn[PCC_FlexCAN0_INDEX] |= PCC_PCCn_CGC_MASK;
    
    // Set CTRL1 Register bit timing fields:
    // PRESDIV (BRP-1) = 4 (Divider = 5)
    // PROPSEG = 6 (7 Tq)
    // PSEG1   = 4 (5 Tq)
    // PSEG2   = 2 (3 Tq)
    // RJW     = 1 (2 Tq)
    // Total Tq = 1 (Sync) + 7 + 5 + 3 = 16 Tq.
    // Sample Point = (1 + 7 + 5) / 16 = 13/16 = 81.25%
    CAN0->CTRL1 = CAN_CTRL1_PRESDIV(4)  |
                  CAN_CTRL1_PROPSEG(6)  |
                  CAN_CTRL1_PSEG1(4)    |
                  CAN_CTRL1_PSEG2(2)    |
                  CAN_CTRL1_RJW(1)      |
                  CAN_CTRL1_CLKSRC(1);  // Bus Clock (40 MHz)
}

[SEC 13] Must-Remember Key Points for Exams

  • [KEY] Bit stuffing inserts an opposite polarity bit after 5 consecutive identical bits.
  • [KEY] Stuffing applies strictly from Start of Frame (SOF) to CRC Sequence.
  • [KEY] Fixed-form fields (CRC Delimiter, ACK, EOF, IFS) are NEVER bit-stuffed.
  • [KEY] If 6 consecutive identical bits are detected in a stuffed field, a Stuff Error is triggered.
  • [KEY] Sample Point is typically configured at 75% - 80% of Nominal Bit Time.
// COMMON EXAM TRAPS & MISCONCEPTIONS
  • Trap: Applying bit stuffing to the End-of-Frame (EOF) field. EOF is 7 fixed recessive bits; stuffing does NOT apply to it.
  • Trap: Placing the sample point at 50% of the bit time. 50% is too early because physical transceiver and cable propagation delays have not yet settled.

[SEC 15] Exam Preparation & Model Questions

Short Answer Questions (1–2 Marks)

2 MARKS Why is bit stuffing used in Controller Area Networks?
Because CAN does not have a separate clock wire. Receivers rely on signal transitions (edges) to synchronize their internal bit clocks. Bit stuffing guarantees an edge at least every 5 bits, preventing clock drift during long sequences of identical bits.
2 MARKS Which fields in a CAN 2.0A frame are NOT subject to bit stuffing?
The CRC Delimiter, ACK Slot, ACK Delimiter, End of Frame (EOF), and Interframe Space (IFS) are fixed-form fields and are not bit-stuffed.

Comprehensive Long Answer Questions (5–10 Marks)

10 MARKS Explain the complete CAN Bit Timing model and Bit Stuffing mechanism. Calculate the register settings (PRESDIV, PROPSEG, PSEG1, PSEG2) to achieve 500 kbps at an 80% sample point from an 80 MHz clock source.
A complete answer covers: (1) Bit timing segmentation diagram (Sync_Seg, Prop_Seg, Phase_Seg1, Phase_Seg2); (2) Hard synchronization vs Resynchronization with SJW; (3) Bit stuffing rule with injection and destuffing examples; (4) Mathematical calculations showing T_q = 62.5 ns (BRP=5), 32 total T_q, and allocation yielding 500 kbps and 80% sample point.

Viva Voce & Technical Interview Questions

VIVA / INTERVIEW What happens if an ECU detects 6 consecutive dominant bits in the Data Field of a received CAN frame?
The receiving ECU immediately detects a Stuff Error, halts frame processing, and broadcasts an Active Error Flag (6 consecutive dominant bits) to destroy the invalid frame on the bus and force the transmitter to re-send.
