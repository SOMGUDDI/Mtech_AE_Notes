Resistors, Voltage Dividers & Sensor Interfacing

Estimated Read Time: 12–15 mins

[SEC 01] Quick Overview

Resistors are passive dissipative circuit components that convert electrical energy into heat, governed by Ohm's Law. In automotive electronics, resistor networks form the fundamental building blocks for voltage dividers, current dividers, pull-up/pull-down terminations, and resistive sensor interfacing (e.g., potentiometers, LDRs, and thermistors).

[SEC 02] Learning Objectives & Prerequisites

What You Will Master:
  • Apply Ohm's Law ($V = IR$) and calculate resistance from material properties ($\rho L / A$).
  • Read 4-band and 5-band standard resistor color codes.
  • Derive and apply the Voltage Divider and Current Divider formulas.
  • Design an analog sensor interface circuit using a variable-resistance sensor (LDR/Thermistor) and a fixed pull-up resistor.
Prerequisites: Basic algebra and electrical concepts (voltage, current).

[SEC 03] Core Concept & Physical Intuition

A microcontroller's ADC pin can only read voltage (0 to 5 V); it cannot read resistance directly. Therefore, whenever you have a sensor whose resistance changes with a physical variable (like a throttle potentiometer or a temperature thermistor), you MUST connect it in series with a fixed reference resistor to form a **Voltage Divider**. As the sensor's resistance changes, the voltage across the divider shifts proportionally, which the ADC can easily measure.

[SEC 05] Rigorous Engineering Theory & Derivations

// RIGOROUS ENGINEERING THEORY

Let's analyze the governing circuit equations: 1. **Resistor Physics & Ohm's Law:** $$R = \frac{\rho \cdot L}{A}, \quad V = I \cdot R, \quad P = V \cdot I = I^2 R = \frac{V^2}{R}$$ - $\rho$ = specific resistivity ($\Omega\cdot\text{m}$), $L$ = length (m), $A$ = cross-sectional area (m$^2$). 2. **Resistors in Series — The Voltage Divider:** - Current through both resistors is identical: $I = \frac{V_{in}}{R_1 + R_2}$. - Voltage across $R_2$ (Output Voltage): $$V_{out} = V_{in} \cdot \frac{R_2}{R_1 + R_2}$$ 3. **Resistors in Parallel — The Current Divider:** - Voltage across both branches is identical: $V = I \cdot R_{eq} = I \cdot \frac{R_1 R_2}{R_1 + R_2}$. - Current flowing through branch $R_1$: $$I_1 = I_{total} \cdot \frac{R_2}{R_1 + R_2}, \quad I_2 = I_{total} \cdot \frac{R_1}{R_1 + R_2}$$

[SEC 08] Step-by-Step Operational Principle

Worked Automotive Light Sensor Circuit: Consider an automatic headlight sensing circuit where $V_{in} = 5.0\text{ V}$, fixed $R_1 = 5.6\text{ k}\Omega$, and $R_2$ is an LDR whose resistance changes with ambient daylight: - **Bright Sunlight ($R_2 = 1.0\text{ k}\Omega$):** $V_{out} = 5.0 \times \frac{1.0}{5.6 + 1.0} = 5.0 \times 0.1515 = \mathbf{0.76\text{ V}}$ (Headlights remain OFF). - **Dusk / Dim Light ($R_2 = 7.0\text{ k}\Omega$):** $V_{out} = 5.0 \times \frac{7.0}{5.6 + 7.0} = 5.0 \times 0.555 = \mathbf{2.78\text{ V}}$ (ECU commands parking lamps ON). - **Night / Dark Tunnel ($R_2 = 10.0\text{ k}\Omega$):** $V_{out} = 5.0 \times \frac{10.0}{5.6 + 10.0} = 5.0 \times 0.641 = \mathbf{3.21\text{ V}}$ (ECU commands main headlamps ON).

[SEC 11] Mathematical Formulas & Numerical Breakdown

Voltage Divider Formula
V_{out} = V_{in} \cdot \left( \frac{R_2}{R_1 + R_2} \right)

  • V: _

Worked Numerical Example:
If Vin = 12V, R1 = 10 kΩ, and R2 = 20 kΩ: Vout = 12 × [20 / (10 + 20)] = 12 × (2/3) = 8.0 Volts.
Current Divider Formula (Two Resistors)
I_1 = I_{total} \cdot \left( \frac{R_2}{R_1 + R_2} \right), \quad I_2 = I_{total} \cdot \left( \frac{R_1}{R_1 + R_2} \right)
Parameter Definitions:
  • I: _
  • I: _
Worked Numerical Example:
If Itotal = 6 A enters a parallel pair of R1 = 2 Ω and R2 = 4 Ω: I1 = 6 × [4 / (2 + 4)] = 6 × (4/6) = 4.0 A (More current flows through the smaller resistor).

[SEC 12] Embedded C Driver & Register Interface

// C Function to Convert Voltage Divider Reading to Sensor Resistance
float calculate_sensor_resistance(float v_in, float v_out, float r_fixed) {
    if (v_out <= 0.01 || v_out >= v_in) {
        return -1.0; // Open circuit or short fault
    }
    // Derived from V_out = V_in * (R_sensor / (R_fixed + R_sensor))
    // V_out * R_fixed + V_out * R_sensor = V_in * R_sensor
    // R_sensor = (V_out * R_fixed) / (V_in - V_out)
    float r_sensor = (v_out * r_fixed) / (v_in - v_out);
    return r_sensor;
}

[SEC 13] Must-Remember Key Points for Exams

  • [KEY] Voltage divides in series: Vout = Vin * [R2 / (R1 + R2)].
  • [KEY] Current divides in parallel: I1 = Itotal * [R2 / (R1 + R2)] (opposite resistor in numerator).
  • [KEY] Microcontroller ADC pins measure VOLTAGE, not resistance directly.
  • [KEY] Resistor color code: BBROYGBVGW (Black=0, Brown=1, Red=2, Orange=3, Yellow=4, Green=5, Blue=6, Violet=7, Grey=8, White=9).
// COMMON EXAM TRAPS & MISCONCEPTIONS
  • Trap: Putting the wrong resistor in the numerator of the current divider formula. In a current divider, $I_1$ uses $R_2$ in the numerator, NOT $R_1$.
  • Trap: Assuming potentiometers change total circuit resistance. The total track resistance between terminal 1 and terminal 3 is fixed; only the wiper split ratio moves.

[SEC 15] Exam Preparation & Model Questions

Short Answer Questions (1–2 Marks)

2 MARKS Why is a fixed pull-up resistor required when interfacing an NTC thermistor to a microcontroller ADC?
An ADC only measures voltage levels, not raw resistance. Placing the thermistor in series with a fixed reference resistor forms a voltage divider that converts temperature-induced resistance changes into proportional voltage changes between 0V and 5V.
2 MARKS What is the current divider formula for finding current through branch $R_1$ in a two-resistor parallel circuit?
I1 = Itotal * [R2 / (R1 + R2)]. Notice that the OPPOSITE resistor (R2) appears in the numerator because smaller resistances draw larger currents.

Comprehensive Long Answer Questions (5–10 Marks)

10 MARKS Derive the Voltage Divider and Current Divider formulas from fundamental Ohm's and Kirchhoff's circuit laws. Design an automotive Throttle Position Sensor (TPS) circuit operating from a 5V supply and calculate its output voltage across wiper angles of 0%, 50%, and 100%.
A complete answer covers: (1) Series circuit schematic and Ohm's law derivation V_out = V_in (R2 / (R1+R2)); (2) Parallel circuit schematic and KCL derivation I1 = I_total (R2 / (R1+R2)); (3) TPS potentiometer wiring diagram (5V, Ground, Wiper); (4) Numerical outputs: 0% angle = 0.0V (0V to 0.5V idle), 50% angle = 2.5V, 100% angle = 5.0V (4.5V to 5.0V WOT).

Viva Voce & Technical Interview Questions

VIVA / INTERVIEW Why are automotive analog sensor signals typically calibrated between 0.5 V and 4.5 V instead of the full 0.0 V to 5.0 V range?
To provide built-in hardware fault diagnostics: If the ADC reads 0.0 V, the ECU detects an open-circuit ground or wire break fault. If the ADC reads 5.0 V, it detects a short-circuit to power supply. Valid sensor operation is strictly confined to 0.5 V – 4.5 V.
