# M.Tech Automotive Engineering Study Guide (Generated Distribution)

This directory contains the standalone, offline-ready static website generated by `build.py`.

## Quick Start
- Open `index.html` in any web browser.
- Or start a local server: `python -m http.server 8000 --directory StudyGuide`
- To rebuild: run `python build.py` from the parent directory.
- To validate: run `python validate.py` from the parent directory.

All features (Search, Dark/Light theme, Bookmarks, Study Progress tracking, Personal Notes) run completely offline in your browser.
