Static and Dynamic Sensor Characteristics

IntermediateExam importance ★★★★★Sensors

Quick overview

Sensor quality is described by static characteristics for steady inputs and dynamic characteristics for changing inputs.

Lecture notes

📘 Sourced lecture synthesis

Lecture 5 recaps sensor characteristics and identifies static characteristics as completed before dynamic characteristics are taken up.

Core concept

💡 Additional explanation

Accuracy, sensitivity, linearity, hysteresis and repeatability describe steady behaviour; response time and bandwidth describe how faithfully a sensor follows change.

Workflow / system view

Physical input
Sensor response
Static or dynamic error
Conditioned signal
Control decision

Worked engineering connection

Example: A slow temperature sensor may be accurate at steady state yet unsuitable for a rapidly changing control loop.
