Embedded System Foundations

BeginnerExam importance ★★★★★Embedded Fundamentals

Quick overview

An embedded system is a purpose-built computing system that senses, decides and controls within a larger product.

Lecture notes

📘 Sourced lecture synthesis

The first contact session introduces embedded processors, ARM Cortex-M4, interfaces and the progression from basics to programming and I/O.

Core concept

💡 Additional explanation

Unlike a general-purpose computer, an embedded system is constrained by real-time behaviour, energy, cost, reliability and its physical interfaces.
